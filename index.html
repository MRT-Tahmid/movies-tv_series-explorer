Project Information

Movies & TV Shows Explorer

An interactive, frontend-only web application for discovering movies and TV shows. Search both catalogs, read details, browse TV episodes by season, and keep movies and shows together in one watchlist that survives a page refresh.

Objectives

  • Fetch and display live data from public REST APIs using fetch() and async/await.
  • Build a responsive, accessible interface with plain HTML, CSS and JavaScript.
  • Handle loading, error and empty states gracefully.
  • Persist user data in the browser with Local Storage.

Main Features

  • Search movies and TV shows by title.
  • Genre filtering and sorting by rating.
  • Detail windows with episodes by season for TV shows.
  • Combined My Watchlist stored in Local Storage.
  • Responsive layout with a dark theme.

Technologies Used

  • HTML5
  • CSS3
  • Vanilla JavaScript (ES6+)
  • Fetch API
  • Local Storage

APIs Used

  • TMDB API for movies.
  • TVmaze API for TV shows.
